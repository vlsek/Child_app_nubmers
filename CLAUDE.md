# Проект: детская игра про цифры (крокодил, 3–4 года)

Vite + Vue 3 (`<script setup lang="ts">`) + TypeScript + Tailwind 3 + Pinia + Vue Router.
Над проектом работают несколько агентов: **сначала прочитай `BACKLOG.md`** (схема уровней, правила, кто что делает) и запиши себя в таблицу.

- Сборка и проверка типов: `npm run build`. Dev-галерея рисунков: `/art`.
- Не пушить в `main` напрямую: ветка `agent-N/...`.
- Никаких токенов и секретов в репозитории.
