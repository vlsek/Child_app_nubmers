## Идеи заданий по цифрам

Все задания должны быть короткими, понятными без чтения, работать на телефоне/планшете и иметь крупные интерактивные объекты. Крокодил — главный герой и повторяющийся персонаж. Необязательно буквально привязывать каждую идею к указанной цифре: подберите количество объектов под свой уровень.

| Идея | Игровое действие / чему учимся | Возможное количество |
|---|---|---|
| Шарики | Крокодил лопает шарики по одному; каждый лопнувший шарик засчитывается | N шариков |
| Свечки | Крокодил задувает свечи по одной; огонёк гаснет после касания | N свечей |
| Лестница | Крокодил поднимается по ступенькам, считая каждую | N ступенек |
| Барашки | Крокодил засыпает и считает прыгающих через кроватку барашков | N барашков |
| Пончики | Помочь крокодилу съесть нужное количество пончиков | N пончиков |

| Велосипед | Крокодил едет и перепрыгивает препятствия; каждое препятствие считается | N препятствий |
| Арбуз | Удалить косточки из кусочка арбуза и перенести их в мусорку, считая каждую | N косточек |
| Раскрась цифру | Закрасить большую цифру выбранными цветами | Одна цифра уровня |

## Правила совместной работы

1. **Сначала посмотри сюда и в код.** Проверь, не существует ли нужная механика уже в проекте.
2. **Работа в своей зоне.** По возможности новые задания держать в отдельных `src/views/LevelN…` и `src/components/levels/levelN/`; не менять общие роутер, стор, базовые стили и другие уровни без необходимости.
3. **Не коммитить чужую работу поверх своей.** Использовать отдельные ветки и PR. Если общий файл изменился параллельно — подтянуть изменения и аккуратно объединить.
4. **Общие механики сначала записать.** Указать путь, props/events, нужные ассеты и пример использования. Не копировать компонент в каждый уровень.
5. **Не добавлять несуществующие звуки.** Если записи пока нет, использовать существующий `useAudio`/браузерный fallback или явно пометить звук как ожидаемый.
6. **Готовность означает проверку.** Указать, что изменено, как открыть уровень, результат сборки и известные ограничения.
7. **Статусы:** Свободно → В работе → На проверке → Готово. Для заблокированной задачи написать причину и что требуется.

## Что требуется от пользователя

- Подготовить/передать, когда будет возможность: крокодил (нейтральный, ест, радуется, удивляется), птичка, слонёнок, велосипед, арбуз/косточки, пончики, шарики и свечи.

- Для каждого ассета указывать, какие состояния/ракурсы доступны. Пока ассетов нет, использовать временные эмодзи/простые SVG и не блокировать разработку.
