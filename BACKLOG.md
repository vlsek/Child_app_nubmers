# Крокодил и цифры — общий бэклог агентов

> Рабочий журнал для 8 агентов. **Прочитай целиком перед началом.** После каждого заметного шага обнови свою строку и раздел «Общие ресурсы». Готово = открывается в приложении, `npm run build` проходит.

## Как устроена игра (каркас от агента 1)

```
Главный экран (/)               ModesView        выбор режима
 └ /learn                       LevelSelectView  карусель машин-цифр 1–10
    └ /learn/N                  LevelHubView     ХАБ цифры N: плитки-активности
       └ /learn/N/<id>          ActivityView     оболочка + ТВОЯ активность
```

**Уровень цифры = набор активностей** (мини-игр). Три есть у всех цифр автоматически: «Посчитай зверей», «Напиши цифру», «Раскрась цифру».
Свои, тематические (шарики, свечи, лестница…) каждая цифра добавляет сама, не трогая общий код.

### Как добавить активность для своей цифры N

1. Папка `src/levels/digit-N/` (только твоя).
2. Компонент активности `src/levels/digit-N/MyActivity.vue`:
   - проп `level: NumberLevel` (цифра, цвет, зверь, машина — см. `src/types/game.ts`);
   - когда ребёнок победил — `emit('complete')`. **Всё остальное делает оболочка:** кнопки «назад/звук», похвала голосом, звезда в прогресс, кнопки «ещё раз / в хаб / дальше».
   - занимай всю доступную область (`h-full w-full`), крупные цели касания (минимум ~64px), без чтения текста.
3. Превью плитки — маленький SVG-компонент `MyPreview.vue` (проп `level`).
4. `src/levels/digit-N/index.ts`:
   ```ts
   import type { ActivityDef } from '@/types/activity'
   import MyPreview from './MyPreview.vue'
   export default [
     { id: 'balloons', title: 'Крокодил лопает шарики', preview: MyPreview,
       component: () => import('./MyActivity.vue') },
   ] satisfies ActivityDef[]
   ```
   Реестр (`src/levels/registry.ts`) подхватывает `digit-*/index.ts` сам. **Роутер, стор, реестр править не нужно.**
5. Образец целиком: `src/levels/digit-4/` (колёса).

Не делай отдельные маршруты и огромные «все задания в одном файле» (так было в `Level8ActivitiesView.vue` — его надо разобрать на активности, см. задачу агента 8).

### Правила

1. Работай в `src/levels/digit-N/`. Общие файлы (`router`, `stores`, `registry`, `useAudio`, `ActivityView`) меняй только если без этого никак, и пиши об этом сюда.
2. **Не пушь в `main` напрямую:** своя ветка `agent-N/...`, потом PR или аккуратный rebase. Перед пушем `git fetch && git rebase origin/main`.
3. Без эмодзи как графики: рисуй SVG (звери — `AnimalHead`, герой — `Crocodile`). Эмодзи допустимы только временно, помечай `TODO`.
4. Звук: `useAudio()`. Новая реплика — `sayLine('имя-файла', 'текст для синтеза')`: пока записи нет, прочитает синтез; когда запись появится в `src/assets/audio/voice/имя-файла.mp3`, подхватится сама. **Записывай нужные реплики в раздел «Запросы звуков».**
5. Для малышей 3–4 лет: нет проигрыша и штрафов, ошибка = мягкое подбадривание (`sayRetry()`), не нужно читать.
6. Проверка: `npm run build`; открой `/learn/N/<id>` на ширине 390 и 1024 пикселей.

## Идеи заданий по цифрам

Все задания должны быть короткими, понятными без чтения, работать на телефоне/планшете и иметь крупные интерактивные объекты. Крокодил — главный герой и повторяющийся персонаж. Необязательно буквально привязывать каждую идею к указанной цифре: подберите количество объектов под свой уровень.

| Идея | Игровое действие / чему учимся | Возможное количество |
|---|---|---|
| Шарики | Крокодил лопает шарики по одному; каждый лопнувший шарик засчитывается | N шариков |
| Свечки | Крокодил задувает свечи по одной; огонёк гаснет после касания | N свечей |
| Лестница | Крокодил поднимается по ступенькам, считая каждую | N ступенек |
| Барашки | Крокодил засыпает и считает прыгающих через кроватку барашков | N барашков |
| Пончики | Помочь крокодилу съесть нужное количество пончиков | N пончиков |
| Колёса | Помочь поставить на машину все колёса; идея цифры 4 закреплена за агентом 1 | 4 колеса |
| Чистка зубов | Маленькая птичка чистит крокодилу зубы; считать зубы/движения щётки | N зубов или движений |
| Чистка зубов: грязь | Убирать грязь/остатки еды между зубами и считать удалённые кусочки | N кусочков |
| Слонёнок | Крокодил осторожно тянет слонёнка за хобот, хобот постепенно удлиняется; считать шаги растяжения | N шагов |
| Велосипед | Крокодил едет и перепрыгивает препятствия; каждое препятствие считается | N препятствий |
| Арбуз | Удалить косточки из кусочка арбуза и перенести их в мусорку, считая каждую | N косточек |
| Раскрась цифру | Закрасить большую цифру выбранными цветами | Одна цифра уровня |
| Напиши цифру | Провести пальцем/мышью по подсказанному контуру цифры | Одна цифра уровня |
| Посчитай предметы | Тапать по одинаковым крупным предметам, получая последовательный голосовой счёт | N предметов |
| Посади цветы | Посадить нужное количество цветов в клумбу | N цветов |
| Собери фрукты | Собрать N фруктов в корзину, не отвлекаясь на лишние предметы | N фруктов |
| Накорми птенцов | Положить каждому птенцу по ягоде и пересчитать ягоды | N ягод |
| Поезд | Прицепить нужное число вагончиков к поезду | N вагончиков |
| Пузыри в ванной | Крокодил лопает мыльные пузыри по одному | N пузырей |
| Найди следы | Найти и нажать N следов крокодила на дорожке | N следов |
