# Крокодил и цифры — общий бэклог агентов

> Рабочий журнал для 8 агентов. **Прочитай целиком перед началом.** После каждого заметного шага обнови свою строку и раздел «Общие ресурсы». Готово = открывается в приложении, `npm run build` проходит.

## Как устроена игра (каркас от агента 1)

```
Главный экран (/)           ModesView        выбор режима
 └ /learn                   LevelSelectView  карусель машин-цифр в пробке (1–10)
    └ /learn/N              SequenceView     нажал на машинку: задания идут по очереди
```

Нажали на машинку-цифру N, и **задания уровня идут одно за другим**: разминка «Крокодил и друзья» (общая для всех цифр), затем свои задания цифры. Кружки вверху показывают, где мы. После победы: похвала голосом и автопереход. Если за 20 секунд не вышло, появляется кнопка «пропустить». Меню-хаба с плитками нет и не будет: малыш не должен выбирать.

### Принципы заданий (для детей 3–4 лет)

- **Герой — крокодил, и в каждом задании он взаимодействует с другими зверьми** (друг приносит пончики, звери едут в машине, помогают, хлопают). Звери: `<AnimalHead :kind="level.animal" />`.
- **Просто:** одно действие — тап или короткое перетаскивание. Нельзя: точная обводка, раскраска, чтение, таймеры, проигрыш. Ошибка = мягкий отказ/подбадривание (`sayRetry()`), никаких штрафов.
- Короткие: 10–30 секунд. Крупные цели касания (от 64 px). Внутри уровня идти от простого к сложному.
- Результат всегда «посчитали до N» голосом: `sayNumber(n)`.

### Как добавить задания для своей цифры N

1. Папка `src/levels/digit-N/` (только твоя).
2. Компонент `src/levels/digit-N/MyActivity.vue`: проп `level: NumberLevel` (цифра, цвет, зверь, машина, см. `src/types/game.ts`), `emit('complete')` когда справился. Рамку, прогресс, похвалу, звезду и «пропустить» делает `SequenceView`.
3. `src/levels/digit-N/index.ts`:
   ```ts
   import type { ActivityDef } from '@/types/activity'
   export default [
     { id: 'balloons', title: 'Крокодил лопает шарики', component: () => import('./MyActivity.vue') },
   ] satisfies ActivityDef[]
   ```
   Порядок в массиве = порядок в уровне. Реестр подхватывает файл сам, **роутер, стор, реестр править не нужно.**
4. Образец: `src/levels/digit-4/` (колёса, пончики, арбуз; перетаскивание в SVG: `SeedsActivity.vue`).
5. Проверка: `/learn` → выбери свою машинку; ширина 390 и 1024. `npm run build`.

### Правила

1. Работай в `src/levels/digit-N/`. Общие файлы (`router`, `stores`, `registry`, `useAudio`, `SequenceView`) меняй, только если без этого никак, и пиши об этом сюда.
2. **Не пушь в `main` напрямую:** ветка `agent-N/...`; перед пушем `git fetch && git rebase origin/main`.
3. Без эмодзи как графики: SVG (`AnimalHead`, `Crocodile`, `Icon`). Эмодзи только временно с `TODO`.
4. Звук: `useAudio()`. Новая реплика: `sayLine('имя-файла', 'текст')`: пока записи нет, читает синтез; запись `src/assets/audio/voice/имя-файла.mp3` подхватится сама. **Каждую новую реплику запиши в «Запросы звуков».**
5. Для быстрой проверки своего задания: `/learn/N?step=K` открывает уровень сразу с задания K (с 0; 0 это разминка).
6. Готово = открывается в приложении и `npm run build` проходит.

## Идеи заданий по цифрам

Все задания должны быть короткими, понятными без чтения, работать на телефоне/планшете и иметь крупные интерактивные объекты. Крокодил — главный герой и повторяющийся персонаж. Необязательно буквально привязывать каждую идею к указанной цифре: подберите количество объектов под свой уровень.

| Идея | Игровое действие / чему учимся | Возможное количество |
|---|---|---|
| Шарики | Крокодил лопает шарики по одному; каждый лопнувший шарик засчитывается | N шариков |
| Свечки | Крокодил задувает свечи по одной; огонёк гаснет после касания | N свечей |
| Лестница | Крокодил поднимается по ступенькам, считая каждую | N ступенек |
| Барашки | Крокодил засыпает и считает прыгающих через кроватку барашков | N барашков |
| Пончики | Помочь крокодилу съесть нужное количество пончиков | N пончиков |
| Колёса | Помочь поставить на машину все колёса; идея цифры 4 закреплена за агентом 1 | 4 колеса |
| Чистка зубов | Маленькая птичка чистит крокодилу зубы; считать зубы/движения щётки | N зубов или движений |
| Чистка зубов: грязь | Убирать грязь/остатки еды между зубами и считать удалённые кусочки | N кусочков |
| Слонёнок | Крокодил осторожно тянет слонёнка за хобот, хобот постепенно удлиняется; считать шаги растяжения | N шагов |
| Велосипед | Крокодил едет и перепрыгивает препятствия; каждое препятствие считается | N препятствий |
| Арбуз | Удалить косточки из кусочка арбуза и перенести их в мусорку, считая каждую | N косточек |
| Раскрась цифру | Закрасить большую цифру выбранными цветами | Одна цифра уровня |
| Напиши цифру | Провести пальцем/мышью по подсказанному контуру цифры | Одна цифра уровня |
| Посчитай предметы | Тапать по одинаковым крупным предметам, получая последовательный голосовой счёт | N предметов |
| Посади цветы | Посадить нужное количество цветов в клумбу | N цветов |
| Собери фрукты | Собрать N фруктов в корзину, не отвлекаясь на лишние предметы | N фруктов |
| Накорми птенцов | Положить каждому птенцу по ягоде и пересчитать ягоды | N ягод |
| Поезд | Прицепить нужное число вагончиков к поезду | N вагончиков |
| Пузыри в ванной | Крокодил лопает мыльные пузыри по одному | N пузырей |
| Найди следы | Найти и нажать N следов крокодила на дорожке | N следов |

## Перетаскивание и звери в полный рост (агент 1)

- **Перетаскивание**: `src/composables/useDrag.ts` (`useDrag`, `near`, `inRect`). Предмет рисуется с центром в (0,0), `home` — стартовая точка. Тап-запасной вариант обязателен: малыш 3–4 лет часто просто тыкает, тогда предмет сам долетает до цели. Образцы: `shared/GiveActivity.vue`, `digit-4/DonutsActivity.vue`, `digit-5/TrainActivity.vue`, `digit-6/ApplesActivity.vue`.
