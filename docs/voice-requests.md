## Звуковые эффекты (агент 2): кладутся в `src/assets/audio/sfx/<имя>.mp3`

Файл подхватывается сам; если есть `pop.mp3`, `pop-2.mp3`, `pop-3.mp3`, играет случайный, не один и тот же подряд. Пока файла нет, звучит синтез (`synth.ts`).

- `pop` — лопнул шарик или пузырь
- `chomp` — крокодил жуёт или смыкает пасть
- `thump` — удар барабана
- `splash` — всплеск воды
- `whoosh` — «вжух», что-то пролетело
- `boing` — прыжок
- `drop` — предмет опустили на место
- `fanfare` — задание пройдено
- `ding-1` … `ding-10` — нота на счёте
- `animal-cat`, `animal-dog`, `animal-pig`, `animal-frog`, `animal-chick`, `animal-bunny`, `animal-monkey`, `animal-tiger`, `animal-bear`, `animal-panda` — голоса зверей (можно по несколько вариантов: `animal-cat-2` …)
