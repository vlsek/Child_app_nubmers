# Сборка и подпись Android-приложения

## 1. Включить автосборку (один раз)

Файл `android-ci/android.yml` должен лежать в `.github/workflows/android.yml`. Токен без права `workflow` не может создать такой файл, поэтому перенесите его вручную на сайте GitHub:

1. Откройте репозиторий → файл `android-ci/android.yml`.
2. Нажмите значок карандаша (Edit this file).
3. В поле имени файла вверху сотрите `android-ci/` и впишите `.github/workflows/`, чтобы получилось `.github/workflows/android.yml` (косая черта создаёт папки).
4. Commit changes → прямо в `main`.
5. Вкладка **Actions** → «Android» → после зелёной галочки откройте запуск и скачайте **krokodil-debug-apk** внизу страницы (Artifacts). Это APK для установки на телефон (разрешите установку из неизвестных источников).

Запустить вручную: Actions → Android → Run workflow.

## 2. Подпись для магазина (Google Play)

1. На своём компьютере (нужна Java) выполните `./scripts/make-keystore.sh`. Придумайте пароли, ответьте на вопросы (имя, организация). Файл `krokodil-release.jks` и пароли храните в надёжном месте и не добавляйте в репозиторий: без этого ключа обновлять приложение в магазине будет нельзя.
2. GitHub → Settings → Secrets and variables → Actions → New repository secret. Создайте 4 секрета: `ANDROID_KEYSTORE_BASE64` (вывод `base64 -w0 krokodil-release.jks`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` (по умолчанию `krokodil`), `ANDROID_KEY_PASSWORD`.
3. Следующий запуск Actions дополнительно соберёт **krokodil-release**: подписанный `app-release.aab` (его загружают в Google Play Console) и `app-release.apk`.
4. Номер версии растёт сам (`VERSION_CODE` = номер запуска), магазин требует, чтобы каждая загрузка была новее предыдущей. Имя версии: `1.0.<номер запуска>`.

Рекомендуется включить в Google Play «Play App Signing»: тогда Google хранит основной ключ, а ваш `jks` служит ключом загрузки, и его потерю можно пережить.

## 3. Для детского приложения в магазине понадобятся

- Политика конфиденциальности (страница в интернете, даже если вы ничего не собираете) и анкета «Контент для детей / Families».
- Значок 512×512 и скриншоты (можно сделать с телефона), короткое и полное описание.
- Номер версии и `appId` (`com.vlsek.krokodil`) после первой загрузки менять нельзя.
